## 二、数据流向图

### 2.1 平台列表加载流程
```
用户访问页面
    │
    ├─► PlatformStore.initialize()
    │       │
    │       ├─► 检测: isTauriRuntime()? 
    │       │       │
    │       │       ├── 是: invoke("get_agents") ──► Rust 后端
    │       │       │
    │       │       └── 否: fetch("/api/agents") ──► API 服务器
    │       │                                        │
    │       │                                        ├─► detectPlatforms()
    │       │                                        │   ├─ 检查 ~/.claude/skills/
    │       │                                        │   ├─ 检查 ~/.agents/skills/
    │       │                                        │   ├─ 检查 ~/.cursor/skills/
    │       │                                        │   └─ 检查 ~/.gemini/skills/
    │       │                                        │
    │       └─► 返回: AgentWithStatus[] ──────────────┘
    │
    └─► 显示平台列表
```

### 2.2 技能列表加载流程
```
用户点击平台
    │
    ├─► SkillStore.getSkillsByAgent(agentId)
    │       │
    │       ├─► 检测: isTauriRuntime()?
    │       │       │
    │       │       ├── 是: invoke("get_skills_by_agent")
    │       │       │
    │       │       └── 否: fetch("/api/skills/${agentId}")
    │       │               │
    │       │               └─► API 服务器
    │       │                   │
    │       │                   ├─► scanDirectory(agent.global_skills_dir)
    │       │                   │   ├─ 读取目录下所有子目录
    │       │                   │   ├─ 查找每个子目录的 SKILL.md
    │       │                   │   ├─ 解析 frontmatter (name, description)
    │       │                   │   └─ 返回: ScannedSkill[]
    │       │                   │
    │       └─► 返回: ScannedSkill[]
    │
    └─► 显示技能列表
```

### 2.3 技能详情加载流程
```
用户点击技能
    │
    ├─► SkillDetailStore.loadDetail(skillId)
    │       │
    │       ├─► 并行调用:
    │       │   ├─ webGetSkillDetail(skillId) ──► fetch("/api/skill-detail/${skillId}")
    │       │   │                                   │
    │       │   │                                   ├─► findSkillById(skillId)
    │       │   │                                   │   ├─ 遍历所有平台目录
    │       │   │                                   │   ├─ 查找匹配的技能目录
    │       │   │                                   │   ├─ 读取 SKILL.md frontmatter
    │       │   │                                   │   └─ 构建详情 + 安装信息
    │       │   │                                   │
    │       │   └─ webGetSkillContent(skillId) ───► fetch("/api/skill-content/${skillId}")
    │       │                                       │
    │       │                                       ├─► findSkillById(skillId)
    │       │                                       │   └─ fs.readFile(技能路径/SKILL.md)
    │       │                                       │
    │       └─► 返回: { detail: SkillDetail, content: string }
    │
    └─► 显示技能详情页面
        ├─► Markdown 渲染 (react-markdown)
        ├─► 安装状态显示
        └─► AI 解释生成按钮
```

### 2.4 AI 解释生成流程
```
用户点击"生成解释"
    │
    ├─► SkillDetailStore.generateExplanation(skillId, content, lang)
    │       │
    │       ├─► 检测: isTauriRuntime()?
    │       │       │
    │       │       ├── 是: invoke("explain_skill_stream") ──► Rust 后端
    │       │       │
    │       │       └── 否: webExplainSkill(skillId, content, lang)
    │       │               │
    │       │               ├─► fetch("/api/explain-skill", {
    │       │               │       method: "POST",
    │       │               │       body: { skillId, content, lang }
    │       │               │   })
    │       │               │
    │       │               └─► API 服务器
    │       │                   │
    │       │                   ├─► 构建提示词 (中文/英文)
    │       │                   │   ├─ 截取内容 (最大 8000 字符)
    │       │                   │   ├─ 添加指令模板
    │       │                   │   └─ 生成分段解释指令
    │       │                   │
    │       │                   ├─► 调用智谱 AI API
    │       │                   │   │
    │       │                   │   ├─► POST https://open.bigmodel.cn/api/paas/v4/chat/completions
    │       │                   │   │   │
    │       │                   │   │   ├─ Headers:
    │       │                   │   │   │   ├─ Authorization: Bearer <API_KEY>
    │       │                   │   │   │   └─ Content-Type: application/json
    │       │                   │   │   │
    │       │                   │   │   └─ Body:
    │       │                   │   │       ├─ model: "glm-5"
    │       │                   │   │       ├─ max_tokens: 1024
    │       │                   │   │       └─ messages: [{ role: "user", content: <提示词> }]
    │       │                   │   │
    │       │                   │   └─► 返回 AI 解释文本
    │       │                   │
    │       └─► 返回: { explanation: string }
    │
    └─► 显示 AI 解释
        ├─► 三段式展示:
        │   ├─► 一句话总结
        │   ├─► 适用场景
        │   └─► 关键功能点
        └─► 支持"重新生成"按钮
```

## 四、技术栈总结

| 层级 | 技术栈 | 说明 |
|------|--------|------|
| **前端** | React 18 + TypeScript | UI 框架 |
| **状态管理** | Zustand | 轻量级状态管理 |
| **构建工具** | Vite 6.4.2 | 开发服务器 + 构建 |
| **UI 组件** | TailwindCSS + shadcn/ui | 样式框架 |
| **Markdown** | react-markdown + remarkGfm | Markdown 渲染 |
| **后端** | Node.js + Express | API 服务器 |
| **AI 服务** | 智谱 GLM-5 | 技能解释生成 |
| **数据存储** | 文件系统 | SKILL.md 文件 |

## 六、安全与访问控制

1. **API 服务器**：
   - 仅监听 localhost:8891
   - 通过 Vite 代理对外暴露
   - 文件读取限制在技能目录内

2. **AI API**：
   - API Key 存储在服务器配置中
   - 使用环境变量或配置文件管理

3. **文件访问**：
   - 路径验证：限制在 ~/.agents/skills/ 等目录
   - 符号链接检查：支持并跟踪 symlink 目标
